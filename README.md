## WuKongIM v3 持久 CMD

目标服务端须支持批量 `/message/cmd/bind`、`/message/cmd/unbind`，再启用：

```yaml
wukongIM:
  v3ExplicitCMDBindings: true
  v3SystemUID: "____system" # 必须与 IM 的 api.system_uid 一致
  cmdSyncAPIURL: "http://wk-node101:5001" # 固定单个进程，同步与确认必须使用同一地址
```

默认关闭，保留 v2 调用方式。启用前先按当前权限补齐已有群成员的 CMD 绑定；绑定从当前尾部之后生效，不会恢复此前未绑定的命令。新建群、添加成员成功后绑定，移除成功后解绑；错误返回给调用方重试。群命令发送不重复扫描或写入全体成员。订阅 `Reset != 0` 必须改为明确的成员移除和添加，避免遗留旧绑定。

持久单聊及定向 CMD 在发送前完成绑定。定向接收者列表最多 1000 项，不能拆分后仍向原范围发送；完整请求体上限 256 KiB。临时 CMD 与普通消息不写绑定。群成员批次按 1000 项拆分，跨 Slot 或跨批次失败可以部分完成，必须重试整个操作后再发送依赖它的 CMD。

`cmdSyncAPIURL` 可独立于其他 IM 请求固定到单一节点。该节点故障时应让同步失败并在恢复后重拉；不能将确认静默转到另一进程。配置为空时沿用 `apiURL`，因此该地址本身必须保持进程亲和。
